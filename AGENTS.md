# Project Instructions

- Do not develop code for backward compatibility or migration.
- Target only the current application, curriculum, and data formats. Do not add legacy adapters, version-specific branches, migration transforms, or compatibility fallbacks for obsolete formats.
- When a breaking change makes existing local development data stale, prefer discarding or manually resetting that data instead of preserving it through application code.
