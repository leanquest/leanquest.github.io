# LeanQuest music

These five MIDI files are generated by `scripts/generate-music.mjs`:

- `title.mid` — William Byrd's “Ave Verum Corpus,” arranged for four synthesized voices using the [public-domain 1921 Oxford University Press score](https://imslp.org/wiki/Ave_verum_corpus_(Byrd,_William)) (IMSLP #232546) as the reference. Note data was checked against [Monique Rio's CC BY 4.0 edition and MIDI](https://stcpress.org/pieces/ave_verum_corpus). This adaptation performs the score's repeat but omits the Amen: alto, tenor, and bass release halfway through the final measure while soprano sustains to the loop boundary.
- `combat.mid` — “Theorem Under Siege”
- `victory.mid` — “Q.E.D. Fanfare”
- `story-broken-axiom.mid` — “Fracture in the First Theorem”
- `story-hall-of-names.mid` — “Names Without End”

The other four cues are original compositions using a retro-JRPG vocabulary. The browser renders every MIDI through Tone.js synthesizers rather than relying on platform MIDI instruments.

The active looping battle cue is `battle.mid`. The generated `combat.mid` remains an alternate composition and is not used by the game.
